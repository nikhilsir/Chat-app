# ChatApp - Real-time Chat

React + Vite frontend, Node.js/Express + Socket.IO backend, and Neon PostgreSQL.

## Deploy to Render (single web service)

1. Push this repository to GitHub.
2. In Render, choose **New + → Blueprint** and select this repository. Render reads `render.yaml`.
3. Set `DATABASE_URL` to your Neon PostgreSQL connection string in the Render service environment. `JWT_SECRET` is generated by Render.
4. Deploy. Open the Render service URL; `/` serves the React app and `/healthz` checks the server.

The frontend uses same-origin `/api` requests and Socket.IO, so it does not call `localhost` in production.

## Local development

Backend: `cd backend && npm install && npm start`

Frontend in another terminal: `cd frontend && npm install && npm run dev`

Open `http://localhost:5173`. Vite proxies API, uploads, and Socket.IO to the local backend during development.

## Required environment variables

- `DATABASE_URL`: Neon PostgreSQL connection string
- `JWT_SECRET`: long random secret (Render Blueprint generates one)
- `PORT`: provided by Render automatically; defaults to 5000 locally
